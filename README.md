# Godot_FlappyBird
 A Classic Flappy Bird clone made with Godot 4. 

## Implemented
- Bird
- jump, gravity, pipes (head and tails), pipe line spawning, pipeline movements, floor, cool textures(sky, clouds, floor, pipes, bird), cool GUI (Score, Best score)
- Jump
- Gravity
- Pipes (Head & Tails)
- PipeLine Spawning
- PipeLine Movements
- Cool Textrues (Sky, Clouds, Floor, Pipes, Bird)
- Cool GUI (Score, Best)

## KEYs
- **SPACE** or **LEFT MOUSE BUTTON** (Jump)
